# ML Foundations: Mathematical Prerequisites

Mathematical foundations for Machine Learning and NLP. This repository contains my notes as I build the mathematical intuition necessary for understanding ML algorithms from first principles.

## About This Repository

Part of my structured transition from Linguistics to NLP Engineering. This repository focuses specifically on the **mathematical foundations** (Phase 1 of my learning plan) - the linear algebra, calculus, and probability/statistics that underpin machine learning.

**Background:** MA in Linguistics, building technical ML skills to specialize in linguistically-informed NLP.

## What's Covered

**Mathematical topics for ML:**
- Linear Algebra
- Calculus (derivatives, gradients, optimization)
- Probability & Statistics

**Learning philosophy:** Understanding concepts deeply before moving to implementation. These notes emphasize intuition and "why" over computation.

## Learning Approach

This repository emphasizes **conceptual understanding before implementation**:

1. **Mathematical intuition first**: Understanding the "why" behind algorithms
2. **Implementation from scratch**: Building core concepts manually before using libraries
3. **Compare with standard tools**: Validating understanding against scikit-learn/PyTorch
4. **Document clearly**: Notes explain concepts as if teaching someone else
